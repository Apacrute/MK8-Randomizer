# Images needed

Each missing image currently shows a fallback (initials or an emoji). Upload a file with **exactly** this name
(capitals matter) to the folder shown and it appears in the next build — no code changes needed.

**How to add one:** on GitHub, open the folder (e.g. `public/images/characters`), choose **Add file → Upload files**,
drop the image in, and commit to `master`. A new APK builds automatically.

PNG with a transparent background works best. Around 120–256 px is plenty.
