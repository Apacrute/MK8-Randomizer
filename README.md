# MK8 Randomizer — Capacitor App

A Mario Kart 8 Deluxe randomizer app for **iOS (App Store)** and **Android (Google Play)**, built with React + Capacitor.

---

## Features
- Randomize character, kart, tires, glider, engine class, and map
- 1–4 player support (each player gets their own loadout)
- Map categories: Standard, DLC, Rainbow Roads, Tour Maps
- **No-Repeat mode** — won't pick the same map twice until all are played
- **Map play counter** — tracks how many times each track has been selected
- **Stats screen** — see your most-played maps, filter/sort, reset counts
- Data persists between sessions using Capacitor Preferences

## 1. Project Setup

```bash
# Install dependencies
npm install

# Install Capacitor CLI globally (optional but helpful)
npm install -g @capacitor/cli
```

---

## 2. Add Your Images

Your images go in the `public/images/` folder. Copy them from your existing project:

```
public/
  images/
    characters/     ← Copy from src/Images/Characters/
    karts/          ← Copy from src/Images/Karts/
    tires/          ← Copy from src/Images/Tires/
    gliders/        ← Copy from src/Images/gliders/
    engine/         ← Copy from src/Images/Engine_Class/
    maps/
      non_dlc/      ← Copy from src/Images/maps/Non_DLC/
      dlc/          ← Copy from src/Images/maps/DLC/
```

> **Important:** The image paths in `src/data/*.ts` use lowercase folder names (e.g. `images/characters/Mario.png`).
> Make sure your filenames match exactly — they are case-sensitive on iOS/Android.

---

## 3. Build the Web App

```bash
npm run build
```

This creates the `dist/` folder that Capacitor wraps.

---

## 4. Add Mobile Platforms

```bash
# Add iOS (Mac only)
npx cap add ios

# Add Android
npx cap add android
```

---

## 5. Sync Your Build

Every time you change code and rebuild, run:

```bash
npm run build
npx cap sync
```

---

## 6. iOS — Open in Xcode

```bash
npx cap open ios
```

In Xcode:
1. Select your development team under **Signing & Capabilities**
2. Change the bundle identifier if needed (e.g. `com.yourname.mk8randomizer`)
3. Connect your iPhone or select a simulator
4. Press ▶ to run

To submit to the App Store:
- Product → Archive
- Then upload via Xcode Organizer or Transporter

---

## 7. Android — Open in Android Studio

```bash
npx cap open android
```

In Android Studio:
1. Let Gradle sync finish
2. Connect your Android device or start an emulator
3. Press ▶ to run

To submit to Google Play:
- Build → Generate Signed Bundle/APK
- Choose Android App Bundle (.aab)
- Upload to Play Console at play.google.com/console

---

## 8. App Icons & Splash Screens

Use the official Capacitor Assets tool to generate all icon sizes from one image:

```bash
npm install -g @capacitor/assets

# Place a 1024×1024 PNG at:  assets/icon.png
# Place a 2732×2732 PNG at:  assets/splash.png

npx capacitor-assets generate
```

## Development Tips

- Run `npm run dev` to test in a browser first — everything works in the browser too
- Use `npx cap run ios` or `npx cap run android` to run directly from terminal
- Live reload during development:
  ```bash
  # In capacitor.config.ts, add:
  server: { url: 'http://YOUR_LOCAL_IP:5173', cleartext: true }
  # Then run: npm run dev
  # And: npx cap run android  (or ios)
  ```
